Architecture overview — Vue 3 + FastAPI + in-memory JSON data

Frontend
  • Vue 3 + Composition API
  • Vue Router 4
  • Vite 5 dev server
  • Axios for HTTP
  • Custom SVG charts
  • i18n (EN / JA)
  • Port 3000
Backend
  • Python FastAPI
  • Pydantic models
  • uv package manager
  • In-memory filtering
  • CORS enabled
  • Port 8001
Data
  • 7 JSON files in server/data/
  • Loaded once at startup
  • No database / no persistence
  • Filtered in Python at request time
  • Tasks & purchase orders held in memory

Data Layer — JSON Files

server/data/
  • inventory.jsonSKU, name, category, warehouse, qty_on_hand, reorder_point, unit_cost
  • orders.jsonorder_number, customer, items[], status, warehouse, category, dates, total_value
  • demand_forecasts.jsonitem_sku, current_demand, forecasted_demand, trend (increasing/stable/decreasing)
  • backlog_items.jsonorder_id, item_sku, qty_needed, qty_available, days_delayed, priority
  • spending.jsonsummary totals, monthly[] (Jan–Dec), category_spending[]
  • transactions.jsondate, description, category, warehouse, amount, vendor, type
  • purchase_orders.jsonstarts empty; populated at runtime via POST /api/purchase-orders
Loading Strategy
  • mock_data.pyload_json_file() reads all 7 files into module-level variables at import time
  • RuntimeAll data lives in memory; changes (tasks, POs) are lost on server restart
  • WarehousesSan Francisco · London · Tokyo
  • CategoriesCircuit Boards · Sensors · Actuators · Controllers
  • StatusesDelivered · Shipped · Processing · Backordered
